# 코드북 (Chords)

개인 연주용 어쿠스틱 기타 웹앱. React + Vite + TypeScript + HeroUI v3 (Tailwind CSS v4).

## 기능

- **튜너**: 마이크 입력을 YIN 알고리즘으로 분석, 바늘 게이지, 자동 줄 인식, 대체 튜닝 6종, A4 기준음 조정
- **송북**: 가사 위 코드 / 마디 단위 코드 진행 악보, 조옮김, ♯/♭ 표기, 자동 스크롤, 진행 반주 재생, 곡에 쓰인 코드 다이어그램
  - 일반 "가사 위에 코드" 악보를 붙여넣으면 자동 변환 (탭 악보, 카포·키·템포 정보 포함)
  - 인기곡은 저작권 때문에 코드 진행만, 저작권이 끝난 곡은 가사 포함
- **코드 사전**: 16가지 코드 종류 × 12 루트, 오픈 코드 + E/A/D 폼 보이싱 자동 생성·검증, 음정/음이름 표시, 스트럼·아르페지오 소리
- **연습**: 메트로놈(박자, 탭 템포), 키별 다이아토닉 코드, 코드 진행 반주(리듬 패턴 4종)

기타 소리는 Karplus-Strong 합성으로 만들어서 샘플 파일이 없습니다.

## 구조

```
src/
  lib/theory.ts      음악 이론, 보이싱 생성, 코드 파싱·조옮김
  lib/audio.ts       기타 소리 합성, 메트로놈, 박자 스케줄러
  lib/pitch.ts       YIN 음높이 검출
  lib/songs.ts       송북 악보 형식 파싱, 붙여넣기 변환
  data/songs.ts      기본 곡 목록
  components/        코드 다이어그램, 코드 카드
  features/          tuner / songs / chords / practice 화면
legacy/              첫 번째 바닐라 JS 버전
```

## 실행

```bash
npm install
npm run dev
```

휴대폰에서 튜너(마이크)를 쓰려면 https 주소가 필요합니다.
