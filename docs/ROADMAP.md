2026-11-03 정리. 출처는 세 가지입니다.
- Ultimate Guitar·GuitarTuna 공식 도움말과 앱스토어 조사

- 리뷰 지적 사항을 실제 코드와 대조한 결과

## 1. 먼저 고칠 버그 (코드에서 확인됨)

| 우선순위 | 위치 | 문제 |
|---|---|---|
| P0 | `features/tuner/useTuner.ts` `start()`/`stop()` | 마이크 권한을 기다리는 중에 화면을 벗어나면 `stop()`이 아무것도 안 하고, 권한 승인 후 마이크가 계속 켜져 있음 |
| P0 | `lib/audio.ts` `strum()` + `SongView.tsx` | 카포를 반영하지 않음. Wonderwall(카포 2) 반주가 실제보다 2반음 낮게 남 |
| P0 | `lib/audio.ts` `damp()` | `v.start >= t`인 음을 건너뛰어서, 정지 직전 최대 0.15초 앞까지 예약된 음이 정지 후에도 울림. 화면 갱신 `setTimeout`도 취소 안 됨 |
| P1 | `components/ChordCard.tsx` `resolveChord()` | `D/F#` 같은 분수 코드의 베이스음을 무시하고 그냥 D로 보여주고 재생 |
| P1 | `SongView.tsx`, `Practice.tsx` | 항상 4/4로 재생. 3/4·6/8 곡도 4박. `N.C.`나 쉼표만 있는 마디는 반주에서 빠짐 |
| P1 | `lib/theory.ts` `parseSongChord()` | `C6/9`, `Am6/9`처럼 `/`가 들어간 코드 이름을 인식하지 못함 |
| P1 | `lib/songs.ts` `isChordLine()` | `A`처럼 한 글자짜리 가사 줄을 코드 줄로 착각할 수 있음 |
| P1 | `lib/storage.ts` `save()` | 저장 실패(용량 초과 등)를 알리지 않아 악보가 사라질 수 있음 |
| P1 | `useTuner.ts` 옥타브 필터 | 직전 음의 2배나 절반에 가까운 음을 무조건 버려서, 실제 옥타브 차이 나는 줄로 넘어갈 때도 무시됨 |
| P2 | `lib/theory.ts` `transposeChord()` | `(pc + semis + 120) % 12`는 조옮김을 -120 넘게 내리면 깨짐. 조옮김 범위 제한 필요 |
| P2 | `Practice.tsx` 아르페지오 | 고정된 줄 순서를 써서 뮤트된 줄 차례에는 소리가 안 남 |

## 2. 튜너 개선

- 음 분석(YIN)을 Worker로 옮기기. 지금은 화면을 그리는 메인 스레드에서 초당 약 30회 분석함
- 수동 모드에서는 고른 줄 주변 주파수만 탐색하도록 범위를 좁혀 계산량 줄이기
- 옥타브 판단은 f, f/2, 2f 후보를 신뢰도로 비교하는 방식으로 바꾸기
- 자동 줄 인식에 "찾는 중 → 따라가는 중 → 고정" 단계를 두어, 몇 프레임 연속 같은 줄일 때만 바꾸기
- 소음 기준을 고정값 대신 기기별로 측정하고, 마이크 설정이 실제로 적용됐는지 `getSettings()`로 확인
- 크로매틱 모드, 커스텀 튜닝, 베이스·우쿨렐레 튜닝, 맞았을 때 알림음, 도레미 표기, 왼손잡이 표시

## 3. 추가할 기능 (Ultimate Guitar·GuitarTuna 대비)

두 앱 모두 조옮김, 자동 스크롤, 카포 표시를 유료로 제공합니다. 이 앱에는 셋 다 이미 있습니다.

| 순위 | 기능 | 난이도 | 참고 |
|---|---|---|---|
| 1 | 연주 모드: 전체 화면, 글자 크기, 화면 꺼짐 방지, 다음 코드 미리보기, 블루투스 페이지 넘기개 | 중 | UG 코드 고정·글꼴 설정 |
| 2 | PWA 오프라인 + IndexedDB 저장 + JSON 백업·복원 | 중~상 | UG 오프라인 |
| 3 | 즐겨찾기·셋리스트·최근 곡 | 중 | UG 플레이리스트 |
| 4 | 크로매틱·커스텀 튜닝 | 중 | GuitarTuna 100개 이상 튜닝 |
| 5 | 카포·분수 코드·보이싱 선택 통합 (운지 모양과 실제 음 분리) | 상 | GuitarTuna 카포 끄기 |
| 6 | 박자표·반복 기호를 이해하는 악보 재생 | 상 | |
| 7 | 코드 단순화 (어려운 코드를 쉬운 코드로) | 중 | UG Simplify (유료) |
| 8 | ChordPro 가져오기·내보내기, 변환 미리보기 | 중 | |
| 9 | 구간 반복, 카운트인, 템포 점점 올리기 | 중 | UG 루프·속도 조절 |
| 10 | 마이크로 내 연주를 듣고 피드백 (단음부터 시작) | 상~매우 상 | UG 연습 모드, GuitarTuna 스마트 스크롤 |

쉽게 붙일 수 있는 것: 코드 퀴즈(다이어그램 보고 이름 맞히기, 귀로 맞히기), 인쇄·PDF, 왼손잡이 모드, 내가 고른 YouTube 영상 옆에 띄우기.

못 하는 것 (라이선스 필요): 공식 곡 목록, 공식 탭, 가사 싱크, 원곡 반주 트랙.

## 4. 코드 구조

- `lib/`를 `domain/music`, `domain/songs`, `audio/`, `storage/`로 나누기
- 재생을 하나의 "재생 세션 + 타임라인" 모델로 통일 (예약 음과 화면 타이머를 같이 취소)
- 목록 화면의 `parseBody()`, 카드의 `resolveChord()` 결과 캐싱
- Vitest를 도입하고 위 버그들을 회귀 테스트로 만들기
